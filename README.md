# 🗄️ Banco de Dados I e II

## 📚 Sobre o Repositório

Este repositório reúne atividades práticas, exercícios e avaliações desenvolvidos nas disciplinas de **Banco de Dados I**, ministrada pelo Prof. Felipe Mota, e **Banco de Dados II**, ministrada pelo Prof. Raphael Hoed.

O objetivo é registrar e organizar os conhecimentos adquiridos ao longo das disciplinas, por meio da criação, manipulação e consulta de bancos de dados, utilizando SQL e o sistema gerenciador de banco de dados MySQL.

## 📂 Estrutura do Repositório

### 📌 Banco de Dados I

Contém scripts SQL desenvolvidos para praticar a criação e estruturação de bancos de dados, tabelas, relacionamentos e consultas.

**Atividades e arquivos:**

- `#PROVA2BD1.sql` – Resolução da Prova 2 (Cervejarias e Fabricante).
- `bdequipe.sql` – Script de banco de dados de equipes.
- `clinicboasaude.sql` – Script de banco de dados de uma clínica.
- `sistemaacademia.sql` – Script de banco de dados de um sistema de academia.
- `sistemacampfutebol.sql` – Script de banco de dados de um campeonato de futebol.
- `sistemaeroprontuario.sql` – Script de banco de dados de prontuário.
- `sistemalabiot.sql` – Script de banco de dados do laboratório.

### 📌 Banco de Dados II

Reúne atividades práticas desenvolvidas em MySQL, com foco no funcionamento interno do mecanismo de armazenamento **InnoDB**, abordando conceitos como Buffer Pool, Redo Log e confirmação de transações.

**Atividades e arquivos:**

- `bd2atv1.sql` – Atividade 1.
- `atv3bd2.sql` – Atividade 3.
- `bd2ex.sql` – Exercícios práticos.

## 🛠️ Tecnologias e Ferramentas

- **SQL:** linguagem utilizada para definição, manipulação e consulta de dados.
- **MySQL:** sistema gerenciador de banco de dados.
- **MySQL Workbench:** ferramenta utilizada para criação, execução e gerenciamento de scripts SQL.

## 🎯 Objetivos de Aprendizagem

- Compreender os fundamentos de bancos de dados relacionais.
- Desenvolver e estruturar bancos de dados.
- Criar tabelas e estabelecer relacionamentos entre elas.
- Elaborar consultas e manipular informações utilizando SQL.
- Conhecer mecanismos internos do MySQL e do InnoDB.
- Aplicar os conhecimentos adquiridos em atividades práticas e avaliações.
